Set up in a few minutes

About two minutes, start to finish.

  1. Download and run the installerOpen SimonFlow-Setup.exe and click through. It installs Simon Flow, downloads the speech engine (about 150 MB), and adds a desktop shortcut.
  2. Press Ctrl + Alt + Space and talkPress it again when you're done. Your words show up wherever your cursor is. It works for free right away.
  3. Optional: add a Claude API keyFor smarter cleanup, styles like Email, and translate, get a key at console.anthropic.com and paste it into Settings.
Windows might warn you. Because Simon Flow is a small independent app, Windows may say "Windows protected your PC." Click More info, then Run anyway. If you add a Claude API key, the small cost of each AI cleanup is billed to your own Anthropic account.
